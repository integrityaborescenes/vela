# vela

Расширение Chrome для настройки звука отдельных вкладок.

## Разработка

- `npm install` — установка зависимостей проекта.
- `npm run dev` — запуск режима разработки.
- `npm run build` — сборка расширения в `dist/`.

Сборка рассчитана на Chrome 116 и новее. Для установки локальной сборки откройте `chrome://extensions`, включите режим разработчика и выберите `dist/` через «Загрузить распакованное».

## Разрешения

- `tabCapture` — получать аудиопоток текущей вкладки после открытия vela пользователем.
- `offscreen` — поддерживать обработку звука после закрытия окна расширения.
- `storage` — локально сохранять настройки вкладок и пресеты.
- `contextMenus` — добавить команду mute в меню вкладки.

Расширение не читает содержимое страниц, не запрашивает доступ ко всем сайтам и не отправляет данные в сеть. Аудио обрабатывается локально средствами браузера. Настройки вкладки удаляются из локального хранилища при её закрытии; пользовательские пресеты остаются.
