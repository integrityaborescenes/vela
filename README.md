# vela
расширение Chrome для настройки звука в отдельных вкладках.

Можно менять громкость от 0% до 200%, настраивать 10 полос эквалайзера, сохранять пользовательские пресеты и выключать звук вкладки через контекстное меню страницы. Настройки каждой вкладки сохраняются, пока она открыта.

## Установка (пока не опубликовано)
1. Склонируй репу, открой папку проекта.
2. Установи зависимости: `npm install`.
3. Собери расширение: `npm run build`.
4. Открой в Chrome `chrome://extensions`.
5. Включи «Режим разработчика».
6. Нажми «Загрузить распакованное расширение» и выбери папку `dist`.
